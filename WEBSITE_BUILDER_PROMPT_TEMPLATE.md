## 🎯 BUILD INSTRUCTIONS FOR AI

Please build this website following these guidelines:

### Structure:
1. Create a single-page website with smooth scroll navigation
2. Include all standard sections: Header, Hero, About, Products/Services, Why Choose Us, Testimonials, FAQ, Contact, Footer
3. Use semantic HTML5 elements
4. Ensure all sections have proper IDs for navigation

### Design:
1. Use modern, premium design aesthetics with:
   - Vibrant gradients
   - Smooth animations
   - Glassmorphism effects
   - Professional color palette
   - Consistent spacing and typography
2. Implement dark mode with smooth transitions
3. Ensure mobile-first responsive design

### Features:
1. **Hero Slider:** Auto-rotating carousel with text overlays
2. **Product Gallery:** Clickable images with lightbox modal, zoom functionality, and navigation
3. **Loading Animation:** Professional page loader with brand logo
4. **Scroll Progress:** Visual indicator at top of page
5. **WhatsApp Integration:** Floating button with pre-filled message
6. **Contact Form:** With validation and success/error messages
7. **Testimonials:** Carousel with customer reviews
8. **FAQ:** Accordion-style expandable questions
9. **Navigation:** Sticky navbar with active section highlighting
10. **Accessibility:** ARIA labels, keyboard navigation, semantic markup

### File Structure:
```
/website
  ├── index.html          (Main HTML file)
  ├── styles.css          (Main stylesheet)
  ├── new-features.css    (Additional features styling)
  ├── script.js           (Main JavaScript)
  ├── new-features.js     (Additional features JS)
  ├── setup.bat           (Local server setup - Windows)
  ├── setup.sh            (Local server setup - Mac/Linux)

  ├── CUSTOMIZATION.md    (Customization guide)
  └── /images             (Product/service images)
      ├── logo.png
      ├── [product1].jpg
      ├── [product2].jpg
      └── ...
```
